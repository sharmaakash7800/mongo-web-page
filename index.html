Configure Backend Server URL

GitHub Pages hosts static web pages. To connect with live MongoDB Atlas data, specify your Express backend server URL (local or hosted on Render/Vercel).

Default local backend server: http://localhost:3000

Connect MongoDB Atlas Step-by-Step

  1. Go to MongoDB Atlas: Open cloud.mongodb.com and click on your cluster (Cluster0).
  2. Click "Connect": Select Drivers (Node.js).
  3. Copy your Connection String: It looks like:
    mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/R2D?retryWrites=true&w=majority
  4. Paste into .env file: Replace <username> and <password> with your database user credentials.
  5. Save & Restart: Restart your server (npm start) and refresh this webpage!
