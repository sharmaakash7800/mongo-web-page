Configure Backend Server URL

GitHub Pages hosts static web pages. To connect with live MongoDB Atlas data, specify your Express backend server URL (local or hosted on Render/Vercel).

Default local backend server: http://localhost:3000

Connect MongoDB Atlas Live Database

  1. Open the .env file in your workspace: 
    MONGODB_URI=mongodb+srv://mis_db_user:<password>@cluster0.cmnpteg.mongodb.net/R2D?retryWrites=true&w=majority
  2. Replace <password>: Put your actual MongoDB database cluster password in place of <password>.
  3. Start the Express API Server: Run npm start or node server.js in your terminal.
  4. Refresh this page: The green status badge will light up and live data will load automatically!
